## 「韋」部件網絡（偉）

「韋」甲骨文 ＝ 囗（城）+ 二至四個止（腳）＝ **眾人繞城**，係「圍」嘅初文。後來被借去解「熟皮」，所以要**再加一個囗**造「圍」攞返本義。

| 字 | 結構 | 韋嘅角色 | 意思 |
|---|---|---|---|
| **韋** | 囗 + 止×2~4 | 本體 | 圍城（本義）→ 借為熟皮 → 今多作姓 |
| **圍** | 囗 + 韋 | 聲兼義 | 包圍（韋外面**再加一個囗**） |
| **衛** | 行 + 韋 | 義符 | 守衛（繞城嘅另一面） |
| **違** | 辵 + 韋 | 聲符 | 離開、違背 |
| **偉** | 亻 + 韋 | **聲符** | 奇特、盛大 |
| 緯／葦／諱／韓／闈／韙／煒／瑋／韡 | 各 + 韋 | 聲符 | 見 [偉.md](偉.md) 3.1 |

**上古音規律（鄭張尚芳 2003）**：\*ɢʷɯl**ʔ**（有喉塞尾）→ 今粵語 **wai5**（偉韙煒暐瑋葦韡）；\*ɢʷɯl（無）→ **wai4**（韋違圍闈幃）。「偉」同「韋」**只差一個喉塞尾**。

## 「青」「爭」部件網絡（靜）—— 以現代書面語撰寫

「靜」是雙聲符字：左半「青」\*sʰleːŋ、右半「爭」\*ʔsreːŋ，上古同屬耕部，**兩個都能表音**，所以四家對「誰表意」講法不一（見 [靜.md](靜.md) 1.2）。

| 字 | 結構 | 聲符 | 意思 |
|---|---|---|---|
| **青** | 生 + 丹（金文或作井） | 生／井（張富海說） | 草木生長之色 |
| **爭** | 又 + 又 + 力 | — | **本義是耕作**（兩手拉犁）；爭奪是假借義 |
| **靜** | 青 + 爭 | **兩個都是** | 【分歧】審（說文）／耦耕（劉洪濤）／無爭而安（張世超） |
| **竫** | 立 + 爭 | 爭 | 亭安。**與「靜」同一反切（疾郢切）**；段玉裁認為「安靜」本字是它 |
| **靖** | 立 + 青 | 青 | 平定。金文「靜」表鎮撫，後世典籍多改作「靖」 |
| **淨／凈／瀞** | 水 + 爭／靜 | 爭／靜 | 清潔（「淨」本義是魯北城門的護城河） |
| **耕** | 耒 + 井 | 井 | 犁田。劉洪濤主張「靜」是「耕」的初文 |
| 靚／凊／婧／請／情／清／精／睛／晴 | 各 + 青 | 青 | 見 [靜.md](靜.md) 1.4 |

**zing6 同音字表（11 字）剛好分成兩族**：青系（靖靚凊婧請）、爭系（竫淨凈）、靜系（瀞）、井系（阱）、乘系（剩）。**9 個來自「靜」自己的部件。**

**「丹」與「井」在「青」裡通用** —— 三件金文「靜」拓本，下半分別寫成「框中一點」「框中套框」「井」，圖片已核實（見 [靜.md](靜.md) 1.1、4.2）。

## 「冄」「女」部件網絡（娜）

「娜」係五張卡入面**結構解釋力最低**嗰隻：《說文》不錄、一張古文字圖都冇（中大字庫成頁冇圖、Wikimedia `娜-seal.svg` 回 404）。要追字源，一定要經「那」→「冄」同「女」兩條路。

| 字 | 結構 | 冄／女嘅角色 | 意思 |
|---|---|---|---|
| **冄（冉）** | 象形 | 本體 | 【分歧】毛髮柔弱下垂（說文、段玉裁）／龜甲邊緣（另說） |
| **𨙻** | 冄 + 邑 | 聲符 | 《說文》「西夷國」。邵瑛：「𨙻，今作那」 |
| **那** | ＝𨙻 | — | 今形不見於《說文》，代詞義最早見唐詩 |
| **娜** | 女 + **那** | **聲符（隔兩層，全啞）** | 纖細柔美；女子名用字 |
| **姌** | 女 + **冄** | 聲符 | 【原文】《說文》「弱長皃」—— **同「娜」係姊妹字，意思幾乎一樣** |
| **髯／苒** | 髟／艸 + 冄 | 聲符 | 下垂嘅鬍鬚／柔弱下垂嘅草 |
| **奴／如／拏／挐** | 女 + X | 女系 | 見 [娜.md](娜.md) 1.4 |

**上古音一條硬線索（鄭張尚芳 2003）**：同一個「冄」聲符，上古分兩批 —— **收 -m**（冉 \*njam、髯、苒、姌…談部）同 **收 -l**（那 \*naːl、挪 \*naːl、**娜 \*naːlʔ**…歌部）。清代徐灝早就講咗：【原文】「𨙻從冄聲，蓋聲變之異。」**注家憑文獻講嘅嘢，同今日嘅構擬對得上。**

**三個粵讀，啱啱各自諧到一個部件**：**naa4** 嘅同音字（拏、挐、蒘）聲符拆到底全部係**女**（＝娜嘅形符）；**no4／no5** 嘅同音字（那、挪、哪）全部係**那**系（＝娜嘅聲符）。呢個係**共時嘅巧合，唔係同源**（上古娜 \*naːlʔ 歌部 vs 拏 \*rnaː 魚部），但係一個好用嘅鈎。

## 「弓」「癹」部件網絡（發）

「發」係六張卡入面**結構解釋力最強**嗰隻：甲骨字形本身就係一幅「射緊箭」嘅圖，唔使靠訓解。而且佢係唯一一隻可以**逐階段睇住佢由表意字變成形聲字**嘅。

| 階段 | 字形 | 六書 |
|---|---|---|
| 甲骨 A | 弓 + **弦畫成斷開**（表顫動） | 指事／表意 |
| 甲骨 B | 弓 + 斷弦 + **攴**（手持棍撥） | 會意 |
| 甲骨 C | 弓 + 弦（唔再斷）+ 攴 | 會意 |
| 金文早期 | 弓 + 弦 | 承甲骨初形 |
| **金文後期（春秋晚期）～今** | **癶** + 弓 + 殳（＝弓 + **癹**聲） | **形聲** |

**關鍵對比**：「弓」＝弓背 + **一條完整嘅弦**；「發」＝**一模一樣嘅弓背 + 弦斷成兩三截**。
**一個「畫斷」嘅動作，就由一件死物變成一個正在發生嘅事件。**（中大原拓＋Wikimedia 摹寫，四張圖對過。）

**「發」同「撥」嘅三重關係**（本卡最硬嗰段）：

| 證據 | 原文 | 級別 |
|---|---|---|
| 撥 从 **發** 聲 | 【原文】《說文》「撥，治也。从手，發聲。」 | 實錘 |
| 癶 **讀若撥** | 【原文】《說文》「𣥠……讀若撥。」 | 實錘 |
| 發 讀 but3／but6 同「撥」完全同音 | 粵語審音配詞字庫 | 實錘 |
| 癹 係「撥」之初文 | 何琳儀（中大轉引） | 一家之言 |

而中大解「發」本義嗰陣，用嘅字正正係【原文】「弓弦被拉**撥**後不斷顫動的樣子」。

**反過嚟，faat3 嗰邊三個唔同系列撞埋**：發（癹系 \*pad）、髮（犮系 \*pod）、法（法系 \*p.kap，**上古收 -p**）。**冇一個同源。** 同一隻字，一個讀音通往血緣，一個讀音通往陌生人。

## 部件網絡：「豕」＝豬

呢兩隻字共用同一個部件。同一隻豬，喺唔同字入面做唔同嘅工：

| 字 | 豕嘅位置 | 豕嘅角色 | 意思同豬嘅關係 |
|---|---|---|---|
| **豕** | 獨體 | 本體 | **豬**（本義）— 《說文》「彘也」 |
| **豬** | 左偏旁（壓窄） | 形符 | 豬（今通用字） |
| **豭** | 左偏旁（壓窄） | 形符 | **公豬** — 《說文》話「家」就係佢省聲 |
| **家** | 下（被宀罩住） | **聲符**（主流）／形符（段玉裁） | 屋 + 豬 |
| **豪** | 下（完整形態） | **形符** | **豪豬**（箭豬） |
| 豚 | 右 | 形符 | 小豬 |
| 逐 | 被辵包住 | 形符 | 追趕（本義：追豬） |
| 冢 | 下 | — | 墳墓 |

**觀察到嘅通則**：「豕」做**左偏旁**（豬、豭）會壓窄、捺變點；做**下部件**（家、豪）保持完整形態、捺可以伸展。

## 方法備註

- 所有 `【觀察】` 標記嘅結論，都係我實際 Read 過字形圖之後寫嘅，唔係靠文字描述推。
- 所有 `【原文】` 標記嘅都係字典／古籍原文照抄。
- 每張卡最尾有「存疑／未驗證」節，列明邊啲係二手轉述、邊啲未親眼證實。
- 學界有分歧嘅地方（例如「家」係會意定形聲）**全部講法並列**，唔會揀一個當定論。
