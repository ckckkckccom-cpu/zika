# 閱讀感覺 · 第一印象

**讀的是**：`pdf/靜.pdf`、`pdf/財.pdf`、`pdf/發.pdf`
**讀法**：由第一頁逐頁讀到最後一頁，三份連續讀完，中間沒有看過任何其他檔案。
**身份**：目標讀者（長者，對漢字有興趣，拿着印出來的紙本讀）。

> 先說明一件事：我手上這三份 PDF 的實際頁數是 **靜 33 頁、財 25 頁、發 30 頁**，
> 不是委託時說的 38／29／35。下文所有頁碼都以 PDF 頁腳印的頁碼為準。

---

## 一句話的總印象

**「前面和後面有重覆」這個感覺是成立的，而且不是錯覺。**

但它只在「靜」和「財」身上成立，**「發」完全沒有這個問題**——
因為「發」根本沒有前面那一層。它是另一種累：不是重覆的累，是**沒有入口**的累。

這兩種累，讀起來的感受完全不一樣，我認為不應該用同一套辦法去處理。

---

## 一、哪幾頁令我覺得「剛才看過」

我把感受到的重覆分成三種，由最硬（同一段東西原樣再出現）到最軟（同一個意思換句話再講）。

### 第 1 種：同一份資料，原樣印兩次（這種最刺眼）

| 卡 | A 處 | B 處 | 重覆的是甚麼 |
|---|---|---|---|
| 靜 | **p.1** 大字底下那條密集資料格 | **p.5–6** 「0. 基本資料」的表 | 粵音、國音、部首、部首外筆畫、總筆畫、Unicode、倉頡、四角、大五碼、中古音、上古音、異體字、頻率、英文義、其他頁碼、部件組合、教部字號——**一項不漏，全部再列一次**。一個橫排、一個直排，內容完全一樣 |
| 財 | **p.1** 密集資料格 | **p.5–6** 「0. 基本資料」 | 同上 |
| 發 | **p.1** 密集資料格 | **p.2–3** 「0. 基本資料」 | 同上 |
| 財 | **p.11** 「字形並排比對（楷書）」財／材／裁／貨 四格大字圖 | **p.15** 「楷書並排（我看過的圖）」財／材／裁／貨 | **同一張圖，印了兩次**，連底下的【觀察】講的話都幾乎一樣（「財與材的右半逐筆相同」）。我翻到 p.15 的時候是真的停下來往回翻，以為自己揭錯頁 |
| 靜 | **p.14** 1.6 部件總表裡的《說文》原文欄 | **p.20–22** 2.2 部件逐個查字典 | 青、爭、生、丹、井、又、力 七個部件的《說文》原文，**兩處逐字相同**。1.6 給一句，2.2 給全套——但那一句就是全套裡的第一句 |
| 財 | **p.12** 1.6 部件總表 | **p.18** 2.2 部件逐個查字典 | 貝、才 的字典義同上情況 |
| 發 | **p.12** 1.6 部件總表 | **p.14–15** 2.2 部件逐個查字典 | 弓、癶、殳 同上。而且這兩節只隔兩頁，最明顯 |

**這一種我認為是真重覆，沒有辯護餘地。** 尤其是第 1 頁那條密集格和 0 節那個表：
第 1 頁那條，正正是我作為讀者最喜歡的一件東西（像漢典，一眼掃完），
但正因為我已經掃完了，翻到第 5 頁再見到一模一樣的十七項，感覺就是「這本書在拖」。

### 第 2 種：同一組內容，換個版面再講一次（這種最多）

這一種全部集中在 v3 的「總覽」和第 3 層之間，是**成體系的**重覆：

| 卡 | 總覽那一格（前面） | 正文那一節（後面） | 重疊程度 |
|---|---|---|---|
| 靜 | **p.3**「同族字」圖卡：靖精清情／淨竫 | **p.16** 1.7 二、兩條軸的兩張表 | 同一批字、同一批《說文》原文、同一個「兩軸都長」的結論。**九成重疊** |
| 靜 | **p.4**「做部件時」：瀞等 7 個字、青 108、爭 30、對比財 2 發 32 | **p.17–18** 1.8 的兩張表 | 數字完全一樣，連「靜跟財一樣，基本上是一個終點」這句話都一字不改地出現兩次。**九成半重疊** |
| 靜 | **p.2**「不同部份結構解釋」：兩個都能表音、四家四說並列 | **p.8** 1.2 的四說表 | 八成 |
| 靜 | **p.4**「同音字引申」：11 字、9 個同源、分五族、靖最實／淨靚最鬆 | **p.24–27** 3.1／3.3 | 八成 |
| 財 | **p.3**「同族字」：貨賄資販／材豺 | **p.13–14** 1.7 二、兩條軸 | 九成 |
| 財 | **p.4**「做部件時」：淽、癤、貝 685／才 39／財 2 | **p.16** 1.8 | 九成半 |
| 財 | **p.5**「其他結果」 | **p.22–23** 4.2／4.4 | 八成 |

讀的時候的實際感受是這樣的：
**總覽那幾頁我讀得很暢順、很有收穫**（靜 p.2–5、財 p.2–5），
然後由 0 節一路讀下去，到 1.7、1.8 的時候會有一下「咦？」——
那不是「更深入」的感覺，是「同一件事再說一次」的感覺。

### 第 3 種：同一句結論，全卡出現四到五次

「財」最嚴重。「**四個通假對象剛好就是其餘四個同音字，一個不多一個不少**」這一句：

- p.1 推理網絡圖底下的一句總結（作為全卡標語印在最當眼處）
- p.5「其他結果」
- p.19 3.1 表底下
- p.22 4.3 標題本身就是這句話
- p.23 4.4 一句總結

**五次。** 第一次看到覺得很妙，第五次看到會開始懷疑是不是自己記性不好。

「靜」也有同樣情況：「字形解釋到它讀 zing6，卻解釋不到它為甚麼解安靜」
出現在 p.1 標語、p.1 網絡圖最底那個方格、p.5「其他結果」第一點、p.31 4.4——**四次**。

## 二、哪裡「沒甚麼料卻佔了很多版」

按我讀的時候真正想快點翻過去的次序排：

1. **存疑／未驗證清單**（靜 p.32–33 十一條、財 p.24–25 十三條、發 p.29–30 十八條）。
   我完全同意這一節必須存在，而且我讀了——但它是**一行一條、條條頂天立地地排**，
   十八條佔掉將近兩頁。內容是短句，版面卻當成正文來排。
2. **來源清單**（靜 p.31–32 十八項、財 p.23–24 十三項、發 p.26–28 十四項）。
   一整頁全是 `https://humanum.arts.cuhk.edu.hk/Lexis/lexi-mf/search.php?word=…`，
   同一個網址重覆七八次，只有最後幾個字不同。紙本上這些網址我一條都不會去打。
   **發的來源第 13 項（p.28）更誇張**：一整格塞滿 CHANT 編號，佔了大半頁。
3. **同音異調字**（靜 p.26、財 p.20、發 p.18）。
   財那一節尤其空：coi1 只有一個「啋」字，coi5／coi6 是「有音無字」——
   三行字佔了一節的位置。這一節本身明言「只列名，不引申」，那就更加不該佔版面。
4. **靜 p.19**：教育部異體字字典七項釋義 + 重編國語辭典六項義項，
   兩份高度重疊的義項清單（止安定／緘默無聲／恬淡平和／端莊不佻達…）**上下排了一整頁**。
   它們講的其實是同一批意思，分別只在書證。並排成一個對照表的話，半頁就夠。
5. **部件的全套字典原文**（靜 p.21–22 的生、丹、井、又、力）。
   五個部件、每個三四本字典的原文，兩頁。這裡我承認是資料的必要成本，
   但它跟 p.14 的 1.6 總表重覆（見上），所以感覺特別長。

## 四、哪幾頁最有價值、最不應該動

這幾頁我讀得很慢、很投入，而且是**別處看不到的東西**：

| 頁 | 為甚麼 |
|---|---|
| **靜 p.7** | 三件金文拓本逐件描述（靜卣框中一點、靜弔鼎框中套框、秦公鎛標準井字）。這是「有人真的把三張圖擺在一起看過」才寫得出來的，我在任何字典都讀不到 |
| **靜 p.9** | 「丹／井／月」那一段——今天寫「青」下半清清楚楚是個「月」，但字源上從來不是月；寫法規範和字源分析回答的是兩個不同問題。**這是三份裡我學到最多的一頁**，值回整份的厚度 |
| **靜 p.10** | 「青」四期演變，那顆圓點由甲骨到金文變成井字的空心、到小篆變回一道短橫。這一段有畫面 |
| **靜 p.30** | 4.3：zing6 那 11 個同音字剛好按「靜」的左右兩半分成兩族。這是整份最漂亮的發現 |
| **財 p.9** | 「才」四期演變，「上端削尖、下端插進地裡的木樁」。寫得我看得見那根樁 |
| **財 p.10** | 那段「我改過一次判斷」——原尺寸看錯了筆畫方向，放大之後改正，並記下教訓。**這一段我很喜歡**，它讓我相信前面所有的【觀察】 |
| **發 p.4** | 「發」和「弓」的四張圖對照：弓是完整一條弦，發是斷成兩三截的弦。一個「畫斷」就把死物變成正在發生的事。**三份裡最精彩的一頁** |
| **發 p.10** | 「廢」小篆裡面是一隻完整的「發」，而「廢」的意思跟「發」剛好相反——所以聲符真的不表意。用一個反例證一條規矩，漂亮 |
| **發 p.22–23** | 發／廢／法三角，四個層面四個不同答案。「問兩個字有沒有關係之前，要先問『在哪一層』」——這句話我會記住 |

這些頁的共通點：**都是【觀察】，都是看過圖之後寫的，都不是抄字典。**
如果要我投票，我會說整個計劃的價值有七成在這些頁上。

## 五、次序對不對？我讀到第幾頁才真正「入到去」

**靜和財**：

- **第 1 頁對我沒有幫助**，甚至有點阻礙。
  那幅推理網絡圖裡寫着「三說都走不通」「同音表是結構鏡像」「解釋不到今義」——
  這些全部是**結論**，而我在第 1 頁還不知道有哪三說、甚麼同音表。
  我第一次看是看不懂的，要讀到 p.30 之後回頭再看才明白它在說甚麼。
  （那條密集資料格倒是很好，我一眼掃完就有個底。）
- **真正入到去是第 2 頁**——「總覽」的「查字典的解釋」「不同部份結構解釋」。
  這兩格寫得非常好，兩三句一點，我一讀就知道這個字的問題在哪。
- **p.2 到 p.5 那四頁，是三份裡我讀得最舒服的四頁。**
- 然後 **p.5 下半忽然跌回「0. 基本資料」**，落差很大：
  剛剛講到「其他結果」，正在興頭上，下一格是部首、筆畫、倉頡碼。
  我明白這是「先出結果、後出考據」的設計，但**中間那道門檻太高了**。

**發**：

- 完全是另一回事。**沒有推理網絡圖、沒有總覽**，p.2 直接進「0. 基本資料」。
- 結果是：**我讀到 p.16（2.3 推導鏈）才第一次看見整個字的全景**，
  讀到 p.20（4.1）才知道結論是甚麼。前面十五頁全是原始材料。
- 而且——**「發」是用廣東話口語寫的**（「呢隻字」「唔係」「係咪」「喺度」「點解」「攞去用」），
  靜和財是書面語。我連續讀三份，由財翻到發的時候，那個語氣斷裂**非常明顯**，
  像是換了一個人在說話。作為要拿給長輩看的東西，我認為這個差別比厚薄嚴重得多。
- 但要公道：**發完全沒有重覆的問題**（因為沒有總覽那一層），
  它 30 頁讀下來，我沒有一次覺得「剛才看過」，只覺得「還未到重點」。

**所以「厚」有兩個不同的病因，不要混為一談：**

- 靜、財：**有入口，但入口的東西在正文再講一次**（重覆型厚）
- 發：**沒有入口，全部平鋪**（沒有分層型厚）

## 六、只准改排版（一句內容都不刪、一處考據都不改），我會怎樣做

按我認為省得最多、又最不傷內容的次序：

### 甲、第 1 頁那條密集資料格和 0 節那個表，只保留一份的版面

兩者內容一模一樣。**不是刪掉一份，是不要再排一次**：
0 節那個表改成跟首頁同一條密集格的樣式（橫排、細字、細線），
或者乾脆讓 0 節就是首頁那條格、正文從 1.1 開始。
**每張卡省 1 至 1.5 頁**，而且一個字都沒有少。

### 乙、1.6 部件總表和 2.2 部件逐個查字典，併成一張表

現在是：1.6 給「一句字典義」，2.2 給「全套原文」——
而那一句就是全套的第一句。把 2.2 的內容補進 1.6 那張表多開幾欄（或者讓 1.6 那一欄可以展開），
兩節合成一節。**每張卡省 1 至 2 頁。**

### 丙、總覽的「同族字」「做部件時」已經有圖，1.7／1.8 只留「圖以外」的東西

不是刪 1.7／1.8 的表，是**把表改成細字、窄行、貼着圖排**，
正文只保留圖上看不到的那幾點（交叉點的發現、部件在別的字裡的位置變形、換位異體）。
現在 1.7／1.8 是用全尺寸表格把總覽的圖重講一次。**每張卡省 1 頁左右。**

### 丁、清單類一律兩欄排

- 存疑／未驗證（十一至十八條）
- 來源清單（十三至十八項）
- 同音異調字（一堆字，現在一行一調）
- 靜 p.19 那兩份義項清單，改成左右並排的對照表

這四樣加起來，**每張卡省 1.5 至 2 頁**，而且清單本來就適合兩欄，讀起來反而更快。

### 戊、重覆出現四五次的那一句結論，只在兩個位置保留全句

第 1 頁的標語 + 4.4 一句總結，這兩處保留。
中間「其他結果」和 3.1／4.3 那幾處，改成指回去（「即首頁那一句」），
**字數不變、版面縮短**。

### 己、給「發」加一層入口，不要給它減

發的問題不是厚，是沒有門。它應該跟靜、財一樣有第 1 頁的網絡圖和總覽七格。
**這會令它多兩三頁，但會令它好讀得多。**
（另外，語體應該統一成書面語——這件事比厚薄重要。）

### 庚、關於第 1 頁那幅推理網絡圖

我不建議刪，但我建議**把它移到「總覽」之後**（即現在的 p.5 附近）。
它是一幅「結論圖」，放在讀者甚麼都未知道的第 1 頁，只能看個熱鬧；
放在讀完總覽七格之後，它會立刻變得很有用——因為那時候每個節點我都認得。
**第 1 頁只留大字 + 那句標語 + 密集資料格**，那是最好的開場。

## 七、粗略估算

上面甲到戊全部做齊，一句內容都沒有刪：

| 卡 | 現在 | 估計之後 |
|---|---|---|
| 靜 | 33 頁 | 約 26–28 頁 |
| 財 | 25 頁 | 約 19–21 頁 |
| 發 | 30 頁 | 約 26–28 頁（先加入口、再壓清單，可能只省一兩頁） |

**但我要說清楚：**
就算一頁都省不了，只要做「甲」（首頁資料格和 0 節不要排兩次）和「丙」
（1.7／1.8 不要把總覽的圖重講一次）這兩件事，
**「剛才看過」的感覺就會消失大半。**
讀者抱怨的其實不是頁數，是**在同一份東西裡被告知同一件事三次**。
頁數只是那個感覺的副產品。

## 八、一句話回答委託人

**「前面和後面有重覆」這個講法成立，但要修正兩點：**

1. **它只適用於靜和財，不適用於發。** 發沒有重覆，發是缺入口。
2. **重覆的來源不是內容寫多了，是同一份內容被排了兩次版。**
   最硬的兩處是「首頁資料格 vs 0 節基本資料表」和「總覽同族字／做部件時 vs 1.7／1.8」，
   加上財那張印了兩次的楷書並排圖。
